# Voice Anti-spoofing with LCNN
(ридми чут-чут напромтил, простите 1 час остался)
PyTorch Project Template-based solution for binary voice anti-spoofing on the Logical Access partition of ASVspoof 2019. The model classifies an utterance as bona fide speech or spoofed speech generated by speech synthesis or voice conversion.

|---|---:|
| ASVspoof 2019 LA dev | 2.6687% |
| ASVspoof 2019 LA eval | **4.7041%** |

## Method

The countermeasure is an LCNN with Max-Feature-Map activations. Audio is converted to mono at 16 kHz, padded or cropped to 4.10625 seconds, and represented by a 128-bin mel-spectrogram computed with FFT size 512, window length 512, and hop length 128. The network uses convolutional MFM blocks, pooling and Batch Normalization. Dropout is placed immediately before the final Batch Normalization layer. A single bona-fide-oriented logit is trained with binary cross-entropy.

Main training parameters:

- Adam, learning rate `1e-4`, weight decay `1e-4`;
- batch size 128 for train and 64 for dev;
- StepLR with step size 1980 and gamma 0.1;
- gradient clipping at 2.0;
- checkpoint selection by minimum global dev EER;
- random seed 1010.

## Installation

Python 3.9 or a compatible Python version is recommended. On Kaggle, enable a GPU accelerator and attach the ASVspoof 2019 dataset before running the commands.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
```

Do not put API keys or private GitHub tokens into source files or repository URLs. For online Comet ML logging, authenticate interactively when prompted or provide the key through the environment:

```bash
export COMET_API_KEY="YOUR_COMET_API_KEY"
```

## Dataset layout

The `la_root` configuration value must point to the directory containing these ASVspoof 2019 LA folders:

```text
LA/
├── ASVspoof2019_LA_train/
│   └── flac/
├── ASVspoof2019_LA_dev/
│   └── flac/
├── ASVspoof2019_LA_eval/
│   └── flac/
└── ASVspoof2019_LA_cm_protocols/
    ├── ASVspoof2019.LA.cm.train.trn.txt
    ├── ASVspoof2019.LA.cm.dev.trl.txt
    └── ASVspoof2019.LA.cm.eval.trl.txt
```

The default Kaggle path is configured in `src/configs/asvspoof.yaml` and `src/configs/inference.yaml`. Override it from the command line if the dataset is attached under another path.

## One-batch pipeline test

The project includes a deterministic balanced one-batch configuration. This test uses 16 train examples as both train and dev data and disables waveform noise.

```bash
python3 train.py --config-name asvspoof_one_batch \
  la_root=/path/to/LA
```

A correct pipeline should be able to overfit this fixed batch and approach perfect training accuracy.

## Full training

```bash
python3 train.py --config-name asvspoof \
  la_root=/path/to/LA \
  writer.workspace=akim-zuev-86 \
  writer.run_name=lcnn_exact_example_seed1010
```

Checkpoints and resolved configuration are written under the configured `saved` directory. The best checkpoint is selected by minimum `dev_EER`. Training and dev losses, train accuracy, dev EER, learning rate, gradient norm, and processing speed are logged directly by the template to Comet ML.

## Evaluation inference

Place the selected project-trained checkpoint at `saved/model_best.pth`, or override `inferencer.from_pretrained`.

```bash
python3 inference.py \
  la_root=/path/to/LA \
  inferencer.from_pretrained=/path/to/model_best.pth \
  inferencer.save_path=asvspoof_eval_exact
```

The generated scores are stored under `data/saved/<save_path>/eval/scores.csv`. Each row is headerless and contains:

```text
utterance_id,bonafide_score
```

Higher values must indicate stronger support for bona fide speech.
